# Water Reminder App

## Descripción
Aplicación desarrollada en Kotlin con Jetpack Compose que utiliza WorkManager para programar recordatorios automáticos de hidratación mediante notificaciones.

## Funcionalidades
- Activar recordatorio de agua
- Ejecución de tareas en segundo plano
- Notificaciones automáticas
- Uso de WorkManager

## Conceptos aplicados
- WorkManager
- Worker
- PeriodicWorkRequest
- Notificaciones
- Jetpack Compose
- Buttons y Layouts

## Estructura
- MainActivity.kt
- ReminderScreen.kt
- ReminderUI.kt
- WaterReminderWorker.kt
- NotificationHelper.kt

## Nota
El repositorio contiene el código fuente principal enfocado en la lógica y estructura de la aplicación.
